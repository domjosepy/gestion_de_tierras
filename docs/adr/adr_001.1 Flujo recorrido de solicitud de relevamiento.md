Flujo recorrido de solicitud de relevamiento

1. CREACIÓN → "pendiente_asignacion_sig" (Grupo: SIG)
   • Tipo: relevamiento
   • Asignación automática al grupo SIG

2. ASIGNACIÓN DIGITALIZADOR → "asignado_a_digitalizador" (Grupo: SIG)
   • Líder SIG asigna a un digitalizador
   • Se guarda en usuario_digitalizador

3. INICIO TRABAJO → "en_proceso_digitalizacion" (Grupo: SIG)
   • Digitalizador comienza el trabajo

4. SUBIR PRECAT → "pendiente_revision_sig" (Grupo: SIG)
   • Digitalizador sube archivos
   • Cambia a pendiente de revisión

5. REVISIÓN SIG → "pendiente_aprobacion_campo" (Grupo: SIG)
   • Líder SIG revisa y aprueba para campo

6. APROBACIÓN CAMPO → "aprobado_para_campo" (Grupo: COORDINACION)
   • Líder SIG aprueba definitivamente
   • Pasa a coordinación

7. GENERAR ORDEN → "orden_trabajo_generada" (Grupo: COORDINACION)
   • Coordinación genera orden de trabajo

8. ASIGNAR RELEVADORES → "asignado_relevadores" (Grupo: RELEVAMIENTO)
   • Se asignan los relevadores de campo
   • Pasa al grupo de relevamiento

9. INICIO CAMPO → "en_ejecucion_campo" (Grupo: RELEVAMIENTO)
   • Relevadores inician trabajo en campo

10. FIN CAMPO → "pendiente_cierre" (Grupo: RELEVAMIENTO)
    • Se completa el trabajo de campo

11. CIERRE → "finalizado" (Grupo: RELEVAMIENTO)
    • Se cierra la solicitud
    • Colonia queda marcada con tiene_relevamiento = True

1. CREACIÓN → "pendiente_asignacion_analista" (Grupo: ANALISIS)
   • Tipo: actualizacion
   • Asignación automática al grupo ANÁLISIS

2. ASIGNACIÓN ANALISTA → "asignado_a_analista" (Grupo: ANALISIS)
   • Líder Análisis asigna a un analista
   • Se guarda en usuario_analista

3. INICIO ANÁLISIS → "en_proceso_analisis" (Grupo: ANALISIS)
   • Analista comienza el trabajo

4. COMPLETAR ANÁLISIS → "pendiente_revision_analista" (Grupo: ANALISIS)
   • Analista completa el análisis
   • (Nota: Este estado no está en tus transiciones)

5. REVISIÓN ANÁLISIS → "pendiente_aprobacion_campo" (Grupo: ANALISIS)
   • Líder Análisis revisa y aprueba para campo

6. APROBACIÓN CAMPO → "aprobado_para_campo" (Grupo: COORDINACION)
   • Líder Análisis aprueba definitivamente
   • Pasa a coordinación

7. SIGUE IGUAL QUE RELEVAMIENTO NUEVO (pasos 7-11)
